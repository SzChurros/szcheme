# szcheme
GTK theme made for Szesktop


Generated using [oomox](https://github.com/cwendling/oomox).


# installation

Download the theme from this github and put it in ~/.themes/.

Then do
```sh
gsettings set org.gnome.desktop.interface gtk-theme 'szcheme'
gsettings set org.gnome.desktop.interface color-scheme 'prefer-dark'
```
